# Security policy

## Supported versions

Security fixes go into the latest release. Update through the app or from the
[releases page](https://github.com/omkarbhad/codecity/releases/latest).

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/omkarbhad/codecity/security/advisories/new)

## What CodeCity does with your code

Analysis runs on your machine. Local folders are read in place; GitHub
repositories are downloaded to a local cache. The GitHub token from sign-in is
kept in the operating system keychain. Nothing is uploaded.
